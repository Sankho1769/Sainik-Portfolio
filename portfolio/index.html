PROJECT / 002 — BIM / REVIT

BIM-Based Residential Building Modelling & Documentation

OVERVIEW
An end-to-end BIM workflow demonstrating planning, modelling, coordination and documentation of a multi-storied residential building using Autodesk Revit.
OBJECTIVE
Create a single source-of-truth BIM model that integrates architectural planning, structural elements and documentation outputs, minimising drafting errors.
SCOPE
Floor plans, door/window/room layouts, staircase and circulation planning, roof modelling, RCC slabs/beams/columns, level coordination and full documentation extraction.
WORKFLOW
01 Project Setup → 02 Architectural Modelling → 03 Structural Modelling → 04 Model Coordination → 05 Drawing & Schedule Extraction
DELIVERABLES
Ground floor plan · Upper floor plans · Roof plan · Front elevation · Building sections · Staircase section · Door & window schedule
TOOLS
Autodesk Revit, parametric families, sheet sets & annotations
SKILLS DEMONSTRATED
BIM modelling (architecture & structure), Revit documentation workflow, drawing coordination and sheet management
