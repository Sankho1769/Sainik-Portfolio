PROJECT / 001 — CASE STUDY

G+2 Residential Building

Overview

This academic minor project focused on the planning, structural layout and AutoCAD drafting of a G+2 reinforced concrete residential building. I prepared it during my Diploma in Civil Engineering.

Objective

My objective was to plan a functional residential building that satisfies fundamental civil engineering principles, and to produce professional AutoCAD documentation that mirrors the real drafting workflows used in consultancy firms.

Scope

My scope covered site planning, ground and first floor planning, roof planning, front and sectional elevation, staircase detailing, isolated column footing detailing, and a door & window schedule.

Tools

I used AutoCAD for 2D drafting, referencing standard IS codes for conceptual detailing.

Skills Demonstrated

This project demonstrates my skills in architectural planning, RCC structural components, foundation planning, staircase detailing, and scaled technical drafting.

PROJECT / 002 — CASE STUDY

BIM-Based Residential Building Modelling & Documentation

Overview

I ran an end-to-end BIM workflow — planning, modelling, coordination and documentation — for a multi-storied residential building, built as a single coordinated model in Autodesk Revit.

Objective

I set out to create a single source-of-truth BIM model integrating architectural planning, structural elements and documentation outputs, minimizing drafting errors through coordinated design.

Workflow

I started with project setup — levels and grids — then moved through architectural modelling, structural modelling and model coordination for clash-free alignment, and finally extracted drawings and schedules directly from the model.

Deliverables

I produced the ground floor plan, upper floor plans, roof plan, front elevation, building sections, staircase section, and door & window schedule — all generated from the coordinated model.

Tools

I worked in Autodesk Revit — parametric families, level/grid coordination, sheet sets and annotations.

Skills Demonstrated

This project demonstrates my BIM modelling across architecture and structure, my Revit documentation workflow, and my drawing coordination and sheet management.
